# Mythree

A live interpreter that sits beside a family's video call: a grandfather speaks Telugu,
his grandson hears English, each in their own voice, and the other way round.

Built by team **Mythreyi** for the Meta Global AI Developer Hackathon.
Source code: https://github.com/vijayam1/mythree

This demo needs a passcode.
